免费仓库 · 部署 · 发布 · 打包：10 套

静态站用 1–8；要后端用 9–10。都有免费档。域名要自己买，部署本身不收钱。

中1 Gitee · 中2 腾讯云 · 中3 阿里云 · 中4 华为云 · 中5 Coding
外1 GitHub Pages · 外2 Cloudflare · 外3 Vercel · 外4 Netlify · 外5 Render

打包通用

  1. 静态站：根目录放 index.html，不要丢在子文件夹里却把根指错。
  2. 前端构建：本地 npm run build，把 dist 或 out 当发布目录。
  3. Git 打包：git tag v1.0.0 后在仓库 Releases 上传 zip。
  4. Docker：有 Dockerfile 再推到 Render / 云函数。纯 HTML 不需要 Docker。

中1 Gitee Pages

  1. 打开 gitee.com 注册，新建仓库，勾公开。
  2. 上传站点文件，默认分支 master。
  3. 仓库 → 服务 → Gitee Pages → 启用，分支选 master，目录填 /。
  4. 等审核通过（国内 Pages 有人工审）。结束地址像 https://用户名.gitee.io/仓库名/。
  5. 改了文件要再点一次更新部署。

中2 腾讯云 CloudBase 静态托管

  1. 打开 腾讯云 CloudBase 开免费环境。
  2. 新建环境 → 静态网站托管 → 上传 zip 或关联 Git。
  3. 运行 tcb hosting deploy dist -e 环境ID（需要装 CloudBase CLI）。
  4. 给一个 .tcloudbaseapp.com 域名。可绑自有域。

中3 阿里云 OSS 静态

  1. 阿里云 OSS 开桶（有免费额度 / 按量）。
  2. 新建 Bucket，读公共。
  3. 基础设置 → 静态网站托管 → 默认首页 index.html。
  4. 上传文件或用 ossutil / 控制台拖拽。
  5. 绑 CDN 和域名后把 Bucket 改私有读 + CDN 回源。

中4 华为云 OBS 静态

  1. 华为云 OBS 开桶。
  2. 新建桶 → 静态网站托管 → 上传 index.html。
  3. 绑自有域或用 OBS 默认域名访问。

中5 Coding Pages

  1. coding.net 建项目与仓库。
  2. 项目 → 持续部署 → 静态网站。
  3. 选分支、构建命令（纯 HTML 留空）、发布目录 /。
  4. 推送后自动出页面地址。

外1 GitHub Pages

  1. github.com New repository，Public。
  2. 上传代码。Settings → Pages → Source 选 Deploy from a branch，branch=main，folder=/root。
  3. 几分钟后地址：https://用户名.github.io/仓库名/
  4. 仓库名若是 用户名.github.io，则根域名直接是站。
  5. 改文件后 push 就重新发布。本站就是这套。

外2 Cloudflare Pages

  1. pages.cloudflare.com 用 GitHub 登录。
  2. Create → Connect Git → 选仓库。
  3. 纯 HTML：Build command 空，Output 空或 /。
  4. Deploy。域名 项目.pages.dev。可在 Cloudflare 绑自有域。

外3 Vercel

  1. vercel.com Import Git 仓库。
  2. 框架自动识别 Next / Vite。纯 HTML 也能 Deploy。
  3. 得 项目.vercel.app。每次 push 自动发布。
  4. 免费档有带宽限制，静态站够用。

外4 Netlify

  1. netlify.com Add new site → Import from Git。
  2. Publish directory 填 / 或 dist。
  3. 得 项目.netlify.app。也可把本地文件夹拖到控制台直接发。

外5 Render

  1. render.com New → Static Site 或 Web Service。
  2. 挂 GitHub。Static：Build 空，Publish .
  3. 要 Node 服务用 Web Service 免费档（会睡眠）。
  4. 域名 项目.onrender.com。

选哪套：只有 HTML/CSS/JS 选 GitHub Pages 或 Cloudflare Pages。要自动构建选 Vercel / Netlify。国内访问稳选 Gitee 或腾讯云。
