打包 App：中外各 5 套

先选技术栈，再打包。iPhone 上架必须苹果开发者账号和 Xcode，没有正规签名的 ipa 不写。

中1 HBuilderX · 中2 Android Studio · 中3 应用市场签名 · 中4 小程序 · 中5 网页转桌面
外1 PWA · 外2 Capacitor · 外3 Flutter · 外4 Tauri/Electron · 外5 Actions 云打包

打包前必看

  1. 包名一旦上架就不要改，如 com.nidegongsi.app。
  2. 图标 1024px，应用名不要套牌。
  3. 安卓要一把自己的签名钥匙 .jks / .keystore，丢了就不能覆盖安装。
  4. 测试包和上架包分开：debug 不能上店。
  5. 网站发布仍见下面「网站部署补充」。

中1 HBuilderX / uni-app（国内最常用）

  1. 下 HBuilderX，安装 App 开发插件。
  2. 文件 → 新建 → uni-app。改 manifest.json：应用名、图标、AppID。
  3. 发行 → 真机运行跑通。
  4. 发行 → 原生 App-云打包：选安卓、填包名、使用 DCloud 公证或自有证书。
  5. 云端出 apk / aab。iOS 要苹果证书，在同一菜单里选 iOS。
  6. 官方文档：uniapp 云打包

中2 Android Studio 打正式包

  1. 下 Android Studio。
  2. Build → Generate Signed App Bundle / APK。
  3. 没钥匙就 Create new：记住别名、密码、存盘路径。
  4. 选 release。上架用 AAB，自己装机用 APK。
  5. 产物在 app/release/。

中3 应用宝 / 华为 / 小米 上架打包要求

  1. 应用宝开放平台：巨量引擎开放平台 与 抖音开放平台不是同一个；安卓应用走 应用宝开放平台。
  2. 准备：营业执照、软著软件著作权、隐私政策 URL、签名后的 aab。
  3. 华为上架要额外签名（AppGallery Connect）。小米要市场账号。
  4. 不要把 debug 包传上去。包名与软著证一致。

中4 微信 / 抖音 / 快手小程序打包

  1. 微信：公众平台 → 开发 → 开发管理 → 提交审核。本地用微信开发者工具或 HBuilderX 发行到小程序。
  2. 抖音小程序：抖音开放平台 创建小程序 → 上传代码包或用 IDE 上传。
  3. 快手小程序：快手小程序后台。
  4. 这三种不是 apk，是平台代码包，审核通过才能搜到。

中5 把现成网站打成桌面软件

  1. Pake：一条命令把 URL 打成 Windows / Mac 安装包。
  2. 用 Electron 自制皮：见国外 4。
  3. 只是套壳，不是原生 App，上架应用市场通过率低。自用够了。

外1 PWA（手机添加到主屏幕）

  1. 站里加 manifest.webmanifest：name、icons、start_url、display=standalone。
  2. 加 Service Worker。必须 HTTPS。
  3. 手机浏览器打开站 → 添加到主屏幕。不走应用市场。
  4. 文档：web.dev/learn/pwa

外2 Capacitor（网页变成 apk）

  1. 官网 capacitorjs.com
  2. npm create @capacitor/app 或在现有前端里 npm i @capacitor/core @capacitor/cli 然后 npx cap init。
  3. npm run build → npx cap add android → npx cap open android。
  4. 到 Android Studio 按中2 打签名包。
  5. iOS：npx cap add ios 后用 Mac + Xcode。

外3 Flutter 打 apk / ipa

  1. 装 Flutter SDK。
  2. flutter create myapp → flutter run。
  3. 安卓发布包：flutter build appbundle。自测 apk：flutter build apk --release。
  4. iOS：Mac 上 flutter build ipa，再上传 App Store Connect / TestFlight。
  5. 签名配置见 Flutter 官方 Android signing。

外4 Tauri / Electron 桌面安装包

  1. Tauri（更轻）：v2.tauri.app → npm create tauri-app → npm run tauri build，出 msi / dmg / deb。
  2. Electron：electronjs.org + electron-builder，出 exe / dmg。
  3. 代码签名：Windows 要证书才能消 SmartScreen；Mac 要 Apple 签名和通知。

外5 GitHub Actions 云打包

  1. 仓库建 .github/workflows/build.yml。
  2. 安卓用 ubuntu-latest + 装 JDK，跑 ./gradlew assembleRelease 或 flutter build apk。
  3. 签名密钥放 GitHub Secrets，不要写进仓库。
  4. Actions 成功后 Artifacts 下 apk，或发到 Releases。
  5. 示例文档：docs.github.com/actions

网站部署补充（不打 apk）
