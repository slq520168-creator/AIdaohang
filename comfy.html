1. 傻瓜式安装

先看显卡。NVIDIA 笔记本用 Comfy Desktop。不想装 Python 用 Stability Matrix。只有 iPhone、没有电脑，只能远程打开电脑上的网页，手机本身跑不动大模型。

方案 A：Comfy Desktop（推荐小白）

  1. 打开 https://comfy.org/download/ 下 Windows 或 macOS。
  2. 系统：Windows 10+，或 macOS 13+ Apple Silicon。Linux 官方还没有安装包。
  3. 磁盘预留 20GB+（软件约 5GB，模型还要几十 GB）。内存 16GB 更稳。
  4. 跑安装程序，开启后在 Welcome 里新建一个 Installation。
  5. 点 Launch。浏览器会打开 http://127.0.0.1:8188。

文档： docs.comfy.org/installation/desktop/overview

方案 B：Stability Matrix 一键

  1. 打开 github.com/LykosAI/StabilityMatrix 下 Releases。
  2. 解压到非 C 盘的空文件夹，双击运行。
  3. 包管理里选 ComfyUI → Install。
  4. 等绿灯，点 Launch。模型以后都丢进 Data/Models，不要丢乱。

方案 C：官方 Portable（Windows NVIDIA）

  1. 到 ComfyUI Releases 下 7z。
  2. 解压后双击 run_nvidia_gpu.bat。没显卡用 run_cpu.bat，会很慢。

驱动：NVIDIA 先装好 Game Ready / Studio 驱动。第一次启动会下 PyTorch，等到命令行出现 Starting server。

2. 多语言界面

  1. 右上设置（齿轮）→ Locale / Language。
  2. 选 简体中文。没有就装自定义节点：ComfyUI-Manager 里搜 translation / AIGODLIKE-ComfyUI-Translation。
  3. Manager 安装：右侧面板 Manager → Install Custom Nodes → 搜 AIGODLIKE → Install → Restart。
  4. 节点上右键 → Convert to multilingual 不存在。换语言只换菜单，工作流 JSON 里的节点名仍是英文，属于正常。

3. 第一次跑通（必做）

  1. 打开后看到布线图。没有就 Load Default。
  2. 最左 Load Checkpoint。红色说没模型：把 .safetensors 放进 models/checkpoints/。
  3. 小白第一个模型建议 SDXL 或 Flux schnell 量化版（显存 8GB 用 GGUF）。去 Hugging Face / Civitai 搜名字下。
  4. 中间 CLIP Text Encode 上箱写提示词，下箱写负向词。
  5. 右下 Empty Latent 宽高：SD1.5 用 512，SDXL 用 1024，Flux 按模型说明。
  6. 点 Queue / 快捷键 Ctrl+Enter。右边 Preview 出图。
  7. 工作流保存：菜单 Save。别人发你的 PNG/图里花带线，直接拖进窗口就能读回节点。

4. 文案工作流

ComfyUI 自己不写文案。用两种做法：

  1. 外部 LLM：ChatGPT / Claude 先写镜头运动、服装、光线、时长 15 秒的分镜文案，再贴进 CLIP 框。
  2. 节点里接 LLM：装 ComfyUI-Custom-Scripts 或 Ollama / LM Studio 节点。左边 Text 节点出提示词，连到图或视频的正向提示。
  3. 中文提示词：Flux / Hunyuan / Wan 对中文更友好。SD1.5 建议英文。
  4. 口播文案不要塞进图模型。图模型只写画面；口播用 TTS（IndexTTS、CosyVoice、F5-TTS 节点）另走一条线。

图提示词示例（英文更稳）：

photorealistic, 18yo East Asian woman in a small cafe, natural window light, visible skin pores, holding a cup, looking at camera, 35mm, shallow depth of field

负向：cartoon, extra fingers, watermark, text, blurry, lowres

5. 图片工作流

  1. 文生图：Checkpoint → CLIP 正负 → KSampler → VAE Decode → Save Image。
  2. 图生图：加 Load Image + IP-Adapter 或 Redux / PuLID（换脸要单独装节点）。
  3. 控姿势：ControlNet OpenPose / Depth / Canny。Preprocessor 节点先识图，再进 ControlNet。
  4. 贴装换装：分割节点 + Inpaint。
  5. 模型放置：
    • checkpoints / unet / diffusion_models
    • loras
    • vae
    • clip / text_encoders
    • controlnet
  6. 显存不够：Manager 里装 ComfyUI-GGUF，下 Q4/Q5 量化。KSampler 把步数改 20。

6. 视频工作流

不要一上来 4K。先 5 秒 480p 跑通。

  1. 文档范例：Hunyuan Video。把官方示例图拖进 ComfyUI，红色节点按提示下模型。
  2. Wan 2.1 / 2.2：文生视频和图生视频都有现成图。显存 8–12GB 选 GGUF。
  3. LTX Video：更快，画质略弱，适合试镜头。
  4. 图生视频：Load Image → I2V 模型 → 帧数 49–81 先，再接 Video Combine。
  5. 对口型：Sonic / LivePortrait 类节点，左边人像 + 右边音频。
  6. 输出：VHS Video Combine，帧率 16–24，格式 mp4。

官方视频模型说明见 docs.comfy.org 的 Video Models。

7. 音乐与配乐

  1. ACE-Step：Comfy 里有现成音乐节点，填歌词/风格，出 wav。
  2. Stable Audio Open：短配乐、环境声。
  3. 不要用图模型转音乐。音乐是独立 checkpoint。
  4. 口播：F5-TTS / IndexTTS / CosyVoice 节点，文本进去出 wav。
  5. 合成：Audio 节点出来的 wav + Video Combine 的视频，用 VHS 或 ffmpeg 压在一起。
  6. 手机端只做收听和上传 wav，不要期待 iPhone 本地跑 ACE-Step。

8. 剪辑合成

  1. Comfy 里可做：切帧、拼接、加字幕图层、调色。长片还是导出后用 CapCut / Premiere。
  2. Video Combine 多段排序：多个视频节点依次连到同一个拼接节点。
  3. 字幕：用字幕文件 + 覆加节点，或导出无字幕版去剪映软件里加。
  4. 定点对齐配乐：先定歌曲时长，再让视频帧数 ≈ 秒数 × 帧率。
  5. 批量：把文案 CSV 读进 List 节点，Queue 打勾 extra options 里 increment。

9. 报错对照

  • Value not in list 模型没放对文件夹，或要 Refresh。
  • CUDA out of memory 降分辨率、改 GGUF、关其它卡密集进程。
  • Missing Node Type Manager 装缺的自定义节点，Restart。
  • 黑屏：VAE 没选对，或用了 SD1.5 的 VAE 解 Flux。
  • 人脸塌：加负向 extra fingers, deformed face；或换军武石少的 checkpoint。

工作流合集可以从社区搜现成图拖进去，不要改人发来的 .bat 跑未知脚本。模型只从 Hugging Face、Civitai、官方文档链接下。
