## 为什么报错
GitHub Pages 还没开。Actions 里 pages 失败是这个原因，不是数据坏了。

手机打开：
1. 仓库 AIdaohang
2. Settings
3. Pages
4. Source 选 **GitHub Actions**
5. 保存
6. 再进 Actions 里把最近一次 pages 点 Re-run

开好后网址是：
https://slq520168-creator.github.io/AIdaohang/

不要直接点 GitHub 里的 index.html，那不是网站。
